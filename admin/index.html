SYNOVA Diagnostic Help Center

Learn how to configure tab communication and test mobile VR workouts.

1. How does the Admin Panel talk to the client?

We utilize the browser's native BroadcastChannel API. All data packets are routed directly inside your device's RAM memory between tabs of the same website/port. No servers, network logs, or localStorage entries are ever generated, maintaining absolute athlete data privacy.

2. Visualising Sensor Outputs

To view the active waveform chart and motion angles, open the client application on your smartphone, navigate to the VR Running Challenge, and move the device (or press Spacebar in a browser tab). The sensor updates will immediately plot on the Sensor Status panel.

3. Controlling Client Settings

Adjusting parameters in the Game Management panel sends signals back to the client tab. For instance, modifying the timer limit immediately updates the client's game countdown lengths without reloading.
